# ArchAngel Bot

This project is an autonomous trading bot for Uniswap, featuring a Solidity smart contract, Node.js backend, and a React/Next.js dashboard.

## How to Use

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Copy `.env` and fill in your secrets (never commit real secrets!).
4. Compile contracts: `npx hardhat compile`
5. Run tests: `npx hardhat test`
6. Start backend: `node server.js`
7. Start frontend: `npm run dev`
